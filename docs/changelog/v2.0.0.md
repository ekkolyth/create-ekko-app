# v2.0.0

## Breaking

- Package manager switched from **pnpm** to **bun** for both running the CLI and scaffolded projects.
- VS Code auto-open removed.
- ESLint not installed by default (Biome is the new option).

## Added

- Real wiring for every selected option (not just deps): providers, middleware, schemas, docker-compose, sample emails/forms.
- **Biome** as a tooling option, replacing eslint.
- **Zod** as a tooling option.
- Better Auth + Drizzle pairing (auto-enables Drizzle).
- Convex deployment provisioned during scaffold via `bunx convex dev --once --configure=new`.
- Drizzle Postgres local stack with `docker-compose.yml`.
- `.env.local` aggregator — single file with all keys grouped by section.

## Changed

- TUI progress bar reflects actual step completion.
- Templates moved to `embed.FS`.
- Step builders are now pure functions, fully unit-tested.

## Removed

- Old root `cli.mjs` and committed `bin/create-ekko-app` (binary now ships only via npm release).
